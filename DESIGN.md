# Week 6 MVC interface

Use the existing Microsoft ASP.NET Core MVC scaffold and Bootstrap assets. Genre and Movie pages share `_Layout.cshtml`, form controls, tables, validation messages and CRUD links with Product pages.

- Colors: reuse Bootstrap primary, danger and text colors; inherit the existing page theme.
- Typography and spacing: reuse site.css and Bootstrap defaults; retain the container and responsive grid.
- Forms: use label/input/validation Tag Helpers, visible validation feedback and the existing focus styles.
- Components: use the generated Index, Details, Create, Edit and Delete views without custom artwork or animation.
- Responsive behavior: check desktop and mobile, keyboard controls and horizontal overflow. Retain the existing theme behavior.
